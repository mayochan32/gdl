## 凡例

各論点は次の4ブロックで書きます。

- **現状** — 今の GDL がどうなっているか（事実）
- **論点** — 何を決める必要があるか
- **結論** — 決まったこと。まだ決まっていないときは `⏳ 未確定` と書く
- **関連する検討** — この論点を扱った検討へのリンク

論点は ID（`XXX-01` など）で参照します。章を並べ替えても ID は変えません。
