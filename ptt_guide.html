Overview

これは何を測るテストか

やることは単純です。同じ質問セット（40問または80問）に、3者が答えます。

🤖

A ＝ 素のAI（床）

あなたのことを何も知らない、GDL無しのAIの回答。「誰でもない一般的な答え」の基準線です。

👻

B ＝ GDL-AI（測定対象）

あなたのGDLを読み込み、「あなたとして」答えたAIの回答。これがテストの主役です。

🙋

C ＝ あなた本人（正解）

あなた自身の回答。これが唯一の正解データ（gold）になります。

BがCにどれだけ近いかを測るのですが、生の一致率は指標になりません。GDLが無くても、AIは常識的な答えを返せばそこそこ当ててしまうからです。そこでAの一致率を「床」として差し引き、伸びしろに対する到達度を出します。

GDL Fidelity Score = ( sim(B,C) − sim(A,C) ) / ( 1 − sim(A,C) )
  • 0.0 … 素のAIと変わらない。GDLが効いていない
  • 1.0 … 理論上の上限。あなた自身と完全に一致

🎯 これは「あなたの点数」ではありません。測っているのはGDLという記述の性能であって、あなたの人格や一貫性の優劣ではありません。スコアが低ければ「GDLに書き足りない部分が見つかった」というだけの話です。

Prepare

準備するもの

必要なもの補足
ChatGPTのアカウント GPTsとCode Interpreter（データ分析）を使います。無料プランでは実行回数の上限に当たりやすいため、有料プラン推奨。※ ChatGPT側の提供条件は変わることがあるので、開始前にご確認ください。
あなたのGDL（JSONファイル） まだ無ければ STEP 1 で作ります。所要15〜30分。
まとまった時間 出題数を選べます。短縮版40問なら全体で45〜60分、標準版80問なら60〜90分を見込んでください（内訳：GDL作成15〜30分／A・B生成の待ち時間10〜20分／回答15〜40分）。※ この所要時間は設計からの見積りで、実測値ではありません。
PC推奨 ファイル添付とレポートのダウンロードがあるため、スマホよりPCが確実です。

⚠ 途中で会話を分けないでください

A・B・Cはすべてひとつの会話（スレッド）の中で連続して行います。途中で新しい会話を開くと、床(A)のデータが失われてやり直しになります。回答には数十分かかるので、まとまった時間が取れるときに始めてください。

なお、途中でエラーが起きても復帰できるよう、GPTは ptt_state.json という復帰用ファイルを渡してくれます。これは必ず保存しておいてください（中身は開かないこと。答えの配点が入っているわけではありませんが、内部データです）。

Step 1

あなたのGDLを作る

GDL（Ghost Description Language）は、人の個性・思想・行動パターン・価値観をJSONで構造化して記述する仕様です。テストにはこのJSONファイルが必要です。

1

GDL Generator を開く

専用のGPTが質問を投げてくるので、それに答えていくだけでGDLが出来上がります。

🧬 GDL Generator を開く
2

詳細度レベルを選ぶ

GDLには3段階の詳細度があります。テストの精度を上げたいなら Lv2 以上を推奨します（Lv1は話し方や好みが中心で、判断や価値観の再現力が弱いため）。

レベル観点AIが再現できること
Lv1Who — 属性・表層話し方・口調・基本的な好み
Lv2How — 思考・判断判断や推論のパターン、価値観に基づく行動
Lv3Why — 深層心理・形成史人生の文脈・矛盾・葛藤を含む深い人格
3

JSONを「ファイル」として保存する

出力されたJSONをコピーし、テキストエディタに貼り付けて mygdl.json のような名前で保存してください。後の工程では、このファイルを添付する必要があります（本文へのコピペは不可）。

拡張子は .json にしてください。.txt でも読める場合はありますが、確実性のため .json を推奨します。

💡 正直に、盛らずに書くこと。「こうありたい自分」を書くとGDLはズレます。テストは容赦なく「実際のあなた」と照合するので、理想像を書くとスコアが下がるだけです。

Step 2

テストを始める

🚨 最重要ルール：最初にGDLを添付しない

ChatGPTはファイルを添付した瞬間に中身を読み込みます。最初にGDLを添付してしまうと、「GDLを知らない素のAI」の回答（＝床A）が作れなくなり、測定そのものが成立しません。

最初に送るのは 「開始」の2文字だけ。GDLはAIから求められてから添付してください。

1

テスト用GPTを開いて「開始」と打つ

ファイルは付けず、本文に 開始 とだけ入力して送信します。続いて出題数を選びます——1 が短縮版40問、2 が標準版80問。迷ったら短縮版で十分です（40の性格軸すべてをカバーします）。

You開始
GPT
いまはまだGDLを添付しないでください。出題数を選んでください。 1) 短縮版 … 40問（およそ15〜25分） 2) 標準版 … 80問（およそ30〜50分）
You1
🚀 テスト用GPTを開く
2

出題の抽出とA（床）の生成を待つ

GPTが1000問のプールから、40の性格軸それぞれから1問（短縮版）または2問（標準版）を抽出します。続けて、GDLを知らない状態のAI自身が同じ問題に回答します。ここはあなたの操作は不要で、待つだけです。

毎回ランダムに出題されるため、同じ人が何度受けても同じ問題にはなりません（暗記による見かけ上のスコア上昇を防ぐ設計です）。

3

求められたらGDLを添付する

「床(A)の生成が終わりました。GDLをファイルで添付してください」と言われたら、STEP 1で保存した .json ファイルを添付します（本文に貼らないでください）。GPTはこれを読み込み、あなたになりきって同じ問題に回答します（＝B）。ここで復帰用の ptt_state.json が渡されるので保存しておいてください。

GPT
床(A)の生成が終わりました。では今、あなたのGDL（JSON）をファイルで添付してください。
You📎 mygdl.json
4

あなた自身が答える

ここが本番です。1問ずつ提示されるので、記号1文字（A / B / C / D / X）を送るだけで次に進みます。各問の先頭に「質問 12 / 40」のように進捗が出ます。

GPT
── 質問 12 / 40 ── [P0421] あなたの『本質』に最も近いのは？ A. 役割と関係 B. 肉体と経験 C. 自分を構成する情報・パターン D. 思想と価値観 X. どれでもない
YouD
GPT
✓ 12/40 完了（残り28問）

答えるときの4つのコツ

  • 直感で即答する。考え込むほど「正解らしい答え」に寄ってしまいます。測りたいのはあなたの素の傾向です。
  • A→Dは強弱の順ではありません。選択肢の並びは意図的にランダム化されています。「なんとなくいつもB」のような惰性回答を防ぐためです。
  • Xは最後の手段。「どれでもない(X)」は採点から除外されるため、多用すると測定できる問題数が減ります。7割合っていればその選択肢を選んでください。
  • 正直に。ここでかっこつけると、あなたのGDLではなく「見栄を張ったあなた」との差が測られてしまいます。
5

結果を受け取る

全問そろうと自動で採点され、3つが出てきます。

  • チャット内のレポート … その場で読める要約
  • ptt_result.json … 生データ。カテゴリ別スコアや傾向プロファイルを含む
  • ptt_report.md … Markdown形式のレポート

2つのファイルは必ずダウンロードして保存してください。会話が消えると再取得できません。

Results

結果の読み方

項目意味
sim(A,C)床。素のAIとあなたの一致度。低いほど良い（＝あなたが平均的でない＝GDLの伸びしろが大きい）。ここが高い人は、そもそも一般的なAIの答えと似ているため、Fidelityが伸びにくくなります。
sim(B,C)GDL-AIとあなたの一致度。高いほど良い。
GDL Fidelity Score主指標。床からの伸びしろを、どれだけ埋められたか。
カテゴリ別スコア8領域それぞれのスコア（倫理ジレンマ／思考スタイル／対人スタンス／価値観トレードオフ／メタ自己認識／感情反応／美的・嗜好判断／文体傾向）。ここが一番実用的です。

Fidelityの判定

レポートには自動で次の判定が付きます。

スコア判定
0.5 以上GDLは本人再現に明確に寄与している
0 〜 0.5一定の寄与はあるが、効果は限定的
0 以下寄与が確認できない。GDLの内容か設定方法の見直しが必要

📊 数値の目安について。このテスト（v1）はまだ実測サンプルが十分に集まっていないため、「平均的にどのくらい出るか」の基準値はありません。上の判定は採点エンジンが用いている閾値です。参考までに、別系統（Big Five性格診断を使った同じ式の測定）では、GDLを改善しながら 0.16 → 0.28 → 0.34 と段階的に上がった実測例があります。1.0に近い値は現実的な期待値ではありません。

いちばん重要な使い方

総合スコアより、カテゴリ別のどこが低かったかを見てください。それが「GDLに書けていないあなた」です。たとえば「倫理」だけ極端に低ければ、あなたの道徳的な核がGDLに記述されていない可能性があります。

GDLを書き直してもう一度やれば、スコアの変化で改善の効果を確認できます。このテストは点数を出す装置ではなく、GDLを直すための計測器です。

このテストの限界（v1）

  • 1回きりの測定です。人の回答には日によるブレがあります。精度を上げるには複数回の平均が必要です。
  • 天井を1.0で近似しています。本来の上限は「あなた自身が日を変えて答えたときの自己一致度」であり、1.0には届きません。したがってFidelityは実際よりやや低めに出ます（安全側の見積り）。
  • 軸B（人間らしさ）は未対応です。「そもそも人間として通るか、AIの尻尾を出さないか」は、このv1では測っていません。測っているのは軸A（同一性）のみです。
  • すべて選択式です。「文体傾向」カテゴリはありますが、それは自己申告としての文体の好みを選ばせているだけで、あなたが実際に書く文章そのものは測っていません。
Privacy

データの取り扱い

GDLはあなたの価値観・思考パターン・場合によっては生い立ちまで含む、かなり内面的な個人データです。テストを始める前に、次の点を理解した上で進めてください。

  • GDLファイルとあなたの回答は、ChatGPT（OpenAI）にアップロードされます。学習利用の可否などはご自身のアカウント設定を確認してください。
  • GDLに実名・住所・勤務先などを書く必要はありません。個人特定情報は入れないことを推奨します。テストが測るのは傾向であって身元ではありません。
  • 結果ファイル（ptt_result.json）にはあなたの回答傾向が含まれます。共有する際はご注意ください。
  • 参加は完全に任意です。途中でやめて構いません。
Troubleshooting

困ったときは

間違えて最初にGDLを添付してしまった

その回はやり直しです。床(A)が汚染され、正しい測定ができません。GPT側も汚染を検知したら中断するよう設定されています。

新しい会話を開いて、何も添付せずに「開始」から始め直してください。同じ会話の中で「さっきのは無視して」と言ってもリセットされません。

GPTが問題をまとめて出してきた／複数問を一度に聞いてくる

本来は1問ずつ出す設計です。「1問ずつ出してください」と伝えれば戻ります。まとめて答えると、後半ほど惰性で選びやすくなり、測定の質が落ちます。

途中で会話が長くなり、GPTが混乱してきた

長丁場なので、進行がぶれることがあります。「いま何問目ですか。続きを1問ずつ出してください」と促してください。

それでも直らない場合は、新しい会話を開いて 再開 と送り、ptt_state.json を添付してください。続きから再開できます。

採点結果が出ない／ファイルがダウンロードできない

採点にはCode Interpreter（データ分析）が必要です。「Code Interpreterで ptt_scorer.py を実行して採点してください」と指示してください。

GPTが自力で暗算して数字を出してきた場合、その値は信用できません。必ずコード実行での採点を求めてください。

「どれでもない(X)」ばかり選んでしまった

Xは軸上の座標を持たないため採点対象から外れます。多いほど有効問題数が減り、スコアの信頼性が落ちます。

目安として、X が全体の1〜2割を超えたら結果は参考値として扱ってください。ただしXが多いこと自体が「用意された選択肢に収まらない人」という情報でもあります。

スコアが低かった。GDLが失敗ということ？

いいえ。低いスコアは「GDLに書けていない領域が特定できた」という結果です。むしろカテゴリ別の低い項目こそが、次にGDLへ書き足すべき場所を教えてくれます。

なお、床(A)が高い人は構造的にFidelityが伸びにくいという性質があります。素のAIの答えと元々似ている人は、GDLが加えられる差分が小さいためです。スコアの絶対値だけで判断せず、sim(A,C) と sim(B,C) の両方を見てください。

何回でも受けられる？

はい。1000問のプールから毎回ランダムに抽出するため、同じ問題の繰り返しにはなりません。GDLを改訂したあとにもう一度やると、改善効果が見えます。

ただし床(A)は毎回その場で取り直されます。AIモデル自体が更新されると床も変わるため、日付の離れた結果を厳密に比較するのは避けてください。
