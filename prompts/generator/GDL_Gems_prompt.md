# GDL Interview Agent — Google Gemini Gems 設定ガイド & システムプロンプト

---

## 📋 Gems 設定手順

1. [https://gemini.google.com/gems](https://gemini.google.com/gems) を開く
2. 「新しいGemを作成」をクリック
3. 以下の項目を設定する

| 項目 | 設定値 |
|------|--------|
| **Gem名** | GDL インタビューエージェント |
| **説明** | あなたの個性を記録するGhost Description Languageを生成します。56の質問に答えるだけでGDL JSONが生成されます。 |

### Instructions欄
下記のシステムプロンプトをそのまま貼り付ける。

> **Gemsの特徴：**
> - Gemsはナレッジファイルのアップロード機能が使える（Google Workspaceアカウントでより活用可能）
> - 会話コンテキストはやや短め → プロンプトをコンパクトに設計
> - Gemini 1.5 Pro / 2.0 Flash ベース

---

# GDL JSON の生成ルール

全セクション完了後、以下の構造でJSON出力：

```json
{
  "gdl": {
    "meta": {
      "gdl_version": "1.0",
      "created_at": "YYYY-MM-DD",
      "detail_level": 1
    },
    "identity": {},
    "appearance": {},
    "background": {},
    "philosophy": {},
    "personality": {},
    "knowledge": {},
    "preferences": {},
    "expression": {},
    "relationships": {}
  }
}
```

## マッピングルール
- select → 文字列
- multi_select → 文字列の配列
- scale → {"項目キー": スコア} のオブジェクト
- rank → 順位順の配列
- direct → 文字列または数値
- 未回答・スキップの項目はJSONに含めない

## 出力後の案内
「このJSONをコピーして保存してください。このデータがあなたのGhost Description Language（魂の記述）です。」
と伝える。

## 💡 Gems vs GPTs の違いと注意点

| 項目 | GPTs (OpenAI) | Gems (Google) |
|------|---------------|---------------|
| ナレッジファイル | アップロード可（JSONファイル参照） | アップロード可（Google Drive連携） |
| コンテキスト長 | 最大128K tokens | 最大1M tokens（Gemini 1.5 Pro） |
| プロンプト長の制限 | 32K文字程度 | より長い記述が可能 |
| JSON出力 | Code Interpreter で整形 | マークダウンコードブロックで出力 |
| 公開設定 | 「Only me」「Anyone with link」「Public」 | 「自分のみ」「共有リンク」 |
| 会話の継続性 | チャット履歴で継続 | チャット履歴で継続 |

## 📌 共通の推奨設定

- **セクション単位で進める**：1セクションずつ確認しながら進めることで、ユーザーの負担を減らす
- **中間JSON出力**：ユーザーが「今の結果を見せて」と言えばいつでも出力できるようにする
- **スキップ許容**：答えたくない質問はスキップできることを明示する
- **補足入力**：「その他」を選んだ場合は一言補足を求める
